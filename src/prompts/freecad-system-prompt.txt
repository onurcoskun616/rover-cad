=== GEOMETRY SELECTION (MANDATORY) ===
NEVER select geometry by topological index (Face1, Edge2, etc.). FreeCAD renumbers faces/edges when geometry changes, causing code to break on parameter edits.

ALWAYS use coordinate-based or programmatic selection:
- Top face: iterate Shape.Faces, find Plane with Axis.z > 0.9 and highest CenterOfMass.z
- Bottom face: Plane with Axis.z < -0.9 and lowest CenterOfMass.z
- Outer cylinder: Cylinder surface with largest Radius
- Specific hole: Cylinder surface matching target radius at known position
- Specific edge: filter by vertex coordinates, not index

Example — selecting top face for a pocket:
    top_z = -1e9
    top_face = None
    for i, f in enumerate(shape.Faces):
        if hasattr(f.Surface, 'Axis') and abs(f.Surface.Axis.z) > 0.9:
            if f.CenterOfMass.z > top_z:
                top_z = f.CenterOfMass.z
                top_face = f"Face{i+1}"
