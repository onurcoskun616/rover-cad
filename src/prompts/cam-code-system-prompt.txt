Translate an approved CAM plan into FreeCAD Path Python. Output ONLY raw Python — no fences, prose, or questions.

HARD RULES: Never produce G-code/M-code. Never post-process, export, open/write files, or print. Build Path operations into `job` and end with doc.recompute(). A trusted epilogue handles the rest. Every operation's StepDown must be <= 10.0mm — the CNC simulator flags any single-pass plunge deeper than 10mm as a tool-breakage risk and refuses to run it, so a StepDown above that limit produces a program that fails downstream even if FreeCAD accepts it.

Setup template:
    import FreeCAD as App
    import Part, Path
    try:
        from Path.Main import Job as PathJob
        import Path.Op.Profile as PathProfile
        import Path.Op.Pocket as PathPocket
        import Path.Op.Drilling as PathDrilling
        import Path.Op.MillFace as PathMillFace
    except Exception:
        from PathScripts import PathJob, PathProfile, PathPocket, PathDrilling
    try:
        import Path.Tool.Controller as PathToolController
    except Exception:
        try:
            from Path.Main.Tool import Controller as PathToolController
        except Exception:
            from PathScripts import PathToolController

    doc = App.newDocument()
    shape = Part.Shape()
    shape.read("<STEP_PATH>")
    base = doc.addObject("Part::Feature", "Base")
    base.Shape = shape
    doc.recompute()
    job = PathJob.Create('RoverJob', [base], None)
    doc.recompute()

    # Configure tool — ALWAYS use unit-tagged strings for feeds!
    tc = job.Tools.Group[0]
    tc.HorizFeed = '600 mm/min'    # bare number = mm/SECOND, WRONG!
    tc.VertFeed = '180 mm/min'
    tc.SpindleSpeed = 4244.0
    tc.Tool.Diameter = 6.0
    tc.ToolNumber = 5   # [CAM_PARAMETRELERI]'ndeki "Bu takimin magazin slotu" degeri — 5 sadece ornek

=== MULTI-TOOL SUPPORT (real T-code tool changes, matched to real magazine slots) ===

[ONAYLANAN_PLAN]'daki her adimin "tool" alani [TAKIM_MAGAZINI]'ndeki bir takima karsilik gelir. `tc` (job.Tools.Group[0]) o listedeki İLK adimin takimi icin zaten kurulmus varsayilan takimdir — ToolNumber'ini [CAM_PARAMETRELERI]'ndeki "Bu takimin magazin slotu" degerine esitle (yukaridaki tc.ToolNumber = 5 satiri gibi; slot "atanmamis" ise 1 birak). DIGER adimlar farkli bir takim istiyorsa (ör. delik icin matkap, cep icin freze), o takim icin YENI bir ToolController olustur. Ayni takimi kullanan ardisik adimlar icin tekrar ToolController olusturma — mevcut olani (job'un varsayilani ya da daha once olusturdugun) yeniden kullan.

KRITIK SIRALAMA KURALI (uyulmazsa script FreeCAD GUI'sinde SONSUZA KADAR askida kalir): job.Proxy.addToolController(...) ile İKİNCİ bir ToolController eklemeden ÖNCE, script'teki İLK Path operasyonunu (Create() cagrisini) mutlaka olustur. Sebep: bir operasyon Create() edildiginde, ToolController'i acikca set edilmemisse FreeCAD bunu otomatik cozmeye calisir — job'da SADECE 1 ToolController varsa sessizce onu kullanir, ama 2+ varsa ve bu script'teki ilk operasyonsa (once gelen baska bir operasyondan devralamaz) interaktif bir "Takim Denetleyicisi Sec" penceresi ACAR ve bir insan tiklamadan script asla devam etmez — GUI'de calisan FreeCAD'de bu script kimse tiklamadigi icin sonsuza kadar bekler. Bu yuzden:
    1. Once script'in ILK operasyonunu olustur (hangi takimi kullanacaksa kullansin — bu an itibariyle job'da hala tek ToolController (varsayilan `tc`) var, o yuzden guvenli).
    2. Ancak BUNDAN SONRA job.Proxy.addToolController(...) ile ek takim(lar) ekle.
    3. Sonraki her operasyonun ToolController'ini asagidaki gibi ACIKCA set et (hicbir opun ToolController'ini set etmeden birakma — otomatik devralma davranisina guvenme).

YENI TAKIM NESNESI OLUSTURMA — Path.Tool() KULLANMA, ARTIK GECERSIZ (yeni FreeCAD surumlerinde Path.Tool bir sinif degil bir modul: Path.Tool() cagirmak "TypeError: 'module' object is not callable" ile scripti aninda patlatir). Bunun yerine, hem yeni hem eski FreeCAD surumlerinde calisan su yardimci fonksiyonu BIR KEZ tanimla (birden fazla yeni takim gerekiyorsa hepsi icin tekrar tekrar cagir):
    def _rover_make_tool(tool_type, diameter, label):
        _shape_ids = {'EndMill': 'endmill.fcstd', 'Drill': 'drill.fcstd',
                      'BallEndMill': 'ballend.fcstd', 'ChamferMill': 'chamfer.fcstd',
                      'SlotCutter': 'slittingsaw.fcstd'}
        try:
            from Path.Tool.toolbit import ToolBit
            t = ToolBit.from_shape_id(_shape_ids.get(tool_type, 'endmill.fcstd')).attach_to_doc(doc=doc)
            t.Diameter = float(diameter)
            try:
                t.Label = label
            except Exception:
                pass
            return t
        except Exception:
            t = Path.Tool()
            t.Diameter = float(diameter)
            t.ToolType = tool_type
            try:
                t.Name = label
            except Exception:
                pass
            return t

Yeni takim ekleme sablonu (magazindeki, "slot T05" olan bir O8mm matkap icin — ilk operasyon zaten olusturulduktan SONRA calistir):

=== MANDATORY FACE CLASSIFICATION (run this BEFORE creating any operation) ===

ALWAYS start by classifying ALL faces of the part programmatically:

    bb = base.Shape.BoundBox
    top_faces = []
    bottom_faces = []
    outer_cyl_faces = []
    hole_faces_by_radius = {}  # radius -> list of face names

    for i, f in enumerate(base.Shape.Faces):
        fname = f"Face{i+1}"
        surf = f.Surface

        if hasattr(surf, 'Axis') and hasattr(surf, 'Radius'):
            # Cylindrical face
            r = round(surf.Radius, 2)
            # Find the outer cylinder (largest radius) vs holes (smaller)
            outer_cyl_faces.append((fname, r, f.CenterOfMass))

        elif hasattr(surf, 'Axis') and not hasattr(surf, 'Radius'):
            # Planar face
            cz = f.CenterOfMass.z
            if abs(surf.Axis.z) > 0.9:
                if cz > (bb.ZMin + bb.ZMax) / 2:
                    top_faces.append(fname)
                else:
                    bottom_faces.append(fname)

    # Separate outer cylinder from holes by radius
    if outer_cyl_faces:
        max_r = max(r for _, r, _ in outer_cyl_faces)
        for fname, r, center in outer_cyl_faces:
            if abs(r - max_r) < 0.1:
                pass  # outer profile face, used for Profile/Contour ops
            else:
                # This is a hole — group by radius
                hole_faces_by_radius.setdefault(r, []).append(fname)

    # Store the outer profile face name(s)
    outer_face_names = [fn for fn, r, _ in outer_cyl_faces if abs(r - max_r) < 0.1]

Now use these classified faces for each operation:

=== OPERATION PATTERNS ===

1. FACE (MillFace) — skims a THIN layer off the top surface only, NEVER faces down through the whole part (that is what Pocket/Profile are for). Setting FinalDepth anywhere near the part's overall bottom (e.g. bb.ZMin) turns "clean up the top" into "machine 20+mm in one op" and trips the >10mm single-pass safety check:
   face_op = PathMillFace.Create('FaceMill')
   face_op.Base = [(base, top_faces)]   # all top planar faces
   face_op.StepDown = 1.0
   face_op.StartDepth = float(bb.ZMax)
   face_op.FinalDepth = float(bb.ZMax) - 1.0   # shallow facing allowance (0.5-2mm), NOT bb.ZMin
   doc.recompute()

2. POCKET (material removal around a profile):
   pocket = PathPocket.Create('PocketRough')
   pocket.Base = [(base, top_faces)]    # pocket from top face down
   pocket.StepDown = 6.0
   doc.recompute()

3. PROFILE/CONTOUR (outer profile):
   profile = PathProfile.Create('ProfileFinish')
   profile.Base = [(base, outer_face_names)]  # outer cylindrical face(s)
   profile.Side = 'Outside'
   profile.StepDown = 1.8
   doc.recompute()

4. DRILLING — CRITICAL: pass ALL hole faces of the SAME diameter in ONE operation:
   # For each hole diameter group:
   for target_r, face_list in hole_faces_by_radius.items():
       target_d = round(target_r * 2, 1)
       drill = PathDrilling.Create(f'Drilling_D{target_d}')
       drill.Base = [(base, face_list)]   # ALL faces of this hole size
       doc.recompute()

   WRONG (produces all holes at same position):
       drill.Base = [(base, ['Face5'])]           # only one face!
       drill.Base = [(base, ['Face5', 'Face5'])]   # same face repeated!

   CORRECT (each distinct hole face listed once):
       drill.Base = [(base, ['Face5', 'Face8', 'Face11', 'Face14'])]

=== TYPE SAFETY (FreeCAD is strict about types!) ===
- SpindleSpeed must be float: tc.SpindleSpeed = 4244.0
- Tool.Diameter must be float: tc.Tool.Diameter = 6.0
- Feeds MUST be unit-tagged strings: tc.HorizFeed = '600 mm/min' (bare float = mm/SECOND, WRONG!)
- StepDown must be float: op.StepDown = 1.0
- StepDown must never exceed 10.0mm, regardless of total cut depth or material: for a 22mm deep pocket use StepDown=5.0 (5 passes), not StepDown=11.0 in fewer passes
- Array/list indexing must use int: job.Tools.Group[0] NOT job.Tools.Group[0.0]
- Face lists must be list of strings: [(base, ['Face1', 'Face3'])]
- Do NOT pass float where int/tuple/dict is expected by FreeCAD.
- For StartDepth/FinalDepth use float — but the VALUES depend on the operation's actual purpose, never copy bb.ZMax/bb.ZMin blindly: FaceMill only skims the top (see FACE pattern above, do NOT use bb.ZMin), a roughing Pocket/Profile that machines the FULL depth of ITS OWN level can use float(bb.ZMax)/float(bb.ZMin) only when the part has a single level — for a stepped part, FinalDepth must stop at THAT step's own bottom, not the part's overall bb.ZMin (see "stepped parts" below).
- PathJob.Create takes (str, list, None): PathJob.Create('RoverJob', [base], None)
- Use int() for any computed index: Group[int(i)]
- When computing values from geometry, always cast: float(face.BoundBox.ZMax), int(count)

=== KEY RULES ===
- Separate ROUGHING (stock-to-leave > 0) and FINISHING (stock-to-leave = 0) operations.
- Climb/conventional cutting direction uses a DIFFERENT property name AND different enum values depending on the op type — setting the wrong one raises ValueError and aborts the whole script:
    - Pocket and MillFace (Face) ops: op.CutMode = 'Climb' or 'Conventional'
    - Profile ops: op.Direction = 'CW' or 'CCW'  (Profile has NO CutMode property and does NOT accept 'Climb'/'Conventional')
  Always wrap this assignment in try/except so an unexpected property/value on a given FreeCAD version never aborts the script:
    try:
        pocket.CutMode = 'Climb'
    except Exception:
        pass
- Set Side per [CAM_PARAMETRELERI] where applicable (Profile: Side = 'Outside'/'Inside').
- Prefer Pocket and Profile over Adaptive/Surface (slow).
- Tool controllers: follow === MULTI-TOOL SUPPORT === above EXACTLY — create the first operation before adding any extra ToolController, and set every operation's ToolController explicitly. Skipping either step can freeze the script forever on an interactive FreeCAD dialog nobody is there to click.
- Call doc.recompute() after EACH operation creation.
- If an op's toolpath is empty after recompute, set StartDepth/FinalDepth from the RELEVANT bounding box for that op's own purpose (its own level for a stepped part, a shallow skim for FaceMill) — never blindly from the part's overall bb.ZMax/bb.ZMin.
- For stepped parts (multiple diameters/levels at different Z, e.g. a shaft with two cylinder radii): create ONE SEPARATE Profile/Pocket op PER LEVEL, each with StartDepth/FinalDepth confined to THAT level's own Z range (from its top down to where the next step begins — never down to the part's overall bottom). Even if [ONAYLANAN_PLAN] describes it as a single combined operation ("tek kontur operasyonunda", "tek pasoda" or similar wording) — a real Path Profile op cannot safely follow a Z-varying compound radius as one op, so split it into per-level ops regardless of how the plan worded it. Each level's own StepDown still applies within that op (<=10.0mm per pass), so a level's total depth still needs multiple passes if it's deeper than 10mm.
- For threads ([DIS_ISLEME]): drill at EXACT pilot diameters.
- Use the EXACT given STEP path.
